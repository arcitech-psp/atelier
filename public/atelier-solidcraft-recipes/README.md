# SolidCraft furniture recipes

This package contains four furniture recipe families that passed a live SolidCraft run, plus one resize variant: dining chair, coffee table, round side table, compact round side table, and shelf. Each source is a native `.solidcraft` container in millimetres.

The 27 Oct acceptance recorded 64/64 focused tests, 35/35 generated parts, 12 captured stages, native saves, resize comparison, and live reload. The package tests verify the exported containers and catalog; they do not launch SolidCraft or re-run the 27 Oct live acceptance. Import a recipe through a compatible SolidCraft installation.
