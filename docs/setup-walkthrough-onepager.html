Which path is for me?

Start with your hardware and account. All paths begin with Node.js 24, pnpm 10+, and pnpm install --frozen-lockfile. Atelier ships no model.

The five-line start

Local model · GPU

  1. Install Node.js 24 and pnpm 10+.
  2. Run pnpm install --frozen-lockfile.
  3. Start your compatible model server; note its base URL and model ID.
  4. First run: set ATELIER_BASE_URL and ATELIER_MODEL; run pnpm start.
  5. Choose a workspace, select Vitruvius, and ask a design question.

Cloud · OmniRoute

  1. Install Node.js 24 and pnpm 10+; run pnpm install --frozen-lockfile.
  2. Install and start OmniRoute: npm install -g omniroute, then omniroute.
  3. Add free-provider keys first in the dashboard; paid keys you own are optional.
  4. Run node profiles/cloud/setup-omniroute-combos.mjs.
  5. Start ATELIER_PROFILE=cloud pnpm start; choose Vitruvius and chat.

ChatGPT plan · official sign-in

  1. Install Node.js 24 and pnpm 10+; run pnpm install --frozen-lockfile.
  2. Start ATELIER_PROFILE=cloud pnpm start.
  3. Open http://127.0.0.1:18345/signin in a browser.
  4. Sign in, choose your workspace and approve plan use for Atelier.
  5. Choose a “ChatGPT plan” model and chat; timings are to be measured.

Keep in mind: cloud prompts and files go to connected providers. ChatGPT-plan usage counts against your plan and its route does not offer image generation. For complete requirements, limits and troubleshooting, use the full walkthrough.
