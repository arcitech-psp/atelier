# FreeCAD

## Purpose

Plans parametric models and drawing sets from checked requirements.

## Tools

dsh-tool-fs, dsh-tool-fs-search, dsh-tool-web

## Services

Select a model in Settings; configure a web provider for references. The user supplies project files, dimensions and any local application connection.

Private app connectors are omitted; no unavailable connector names are shipped.

Private CAD application connectors are omitted; the profile can prepare plans and scripts from supplied files.
