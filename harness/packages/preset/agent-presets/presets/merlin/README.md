# Merlin

## Purpose

Plans YouTube titles, B-roll and storyboards from supplied scripts.

## Tools

atelier-canvas, dsh-tool-web

## Services

Select a model in Settings. Configure a web provider for research; image generation is optional. Video editing and stock-footage services are not included.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds Merlin for YouTube titles, storyboards and B-roll planning with optional canvas concepts.
