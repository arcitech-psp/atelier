# Standard

## Purpose

A practical assistant for research, project files and general work.

## Tools

dsh-tool-fs, dsh-tool-fs-search, dsh-tool-web

## Services

Select a model in Settings and configure a web provider when online research is needed. Project file access follows the selected workspace and app guardrails.

Private app connectors are omitted; no unavailable connector names are shipped.

Updates Standard with portable file and configured web tools and no machine-specific assumptions.
