# CAD

## Purpose

Plans 2D CAD drawings and helps review supplied drafting files.

## Tools

dsh-tool-fs, dsh-tool-fs-search, dsh-tool-web

## Services

Select a model in Settings; configure a web provider if standards or references need research. The user supplies CAD files and drawing requirements.

Private app connectors are omitted; no unavailable connector names are shipped.

Private CAD application connectors are omitted; the profile works with supplied files and public tools.
