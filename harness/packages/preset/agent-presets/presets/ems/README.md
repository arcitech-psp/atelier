# EMS

## Purpose

A flexible workspace for general research, writing and file-based tasks.

## Tools

dsh-tool-fs, dsh-tool-fs-search, dsh-tool-web

## Services

Select a model in Settings. Configure a web provider only when online research is needed; project files are optional.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds EMS as a flexible profile using public file and web tools configured by the user.
