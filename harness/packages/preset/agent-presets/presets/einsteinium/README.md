# Einsteinium

## Purpose

Researches regulations, codes and data for a jurisdiction the user names.

## Tools

dsh-tool-web, dsh-tool-fs, dsh-tool-fs-search

## Services

Select a model in Settings and configure a web provider. A project workspace is optional for supplied documents.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds jurisdiction-neutral, source-first research for codes, regulations, documents and data.
