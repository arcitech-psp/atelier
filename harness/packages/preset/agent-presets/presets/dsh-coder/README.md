# DSH Code Proposals

## Purpose

Proposes focused code changes from a supplied source packet; no tools.

## Tools

No tools; drafts from supplied conversation content.

## Services

Select a model in Settings and provide the source packet in the conversation. No additional service is required.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds DSH Code Proposals as a no-tools profile for reviewed, packet-based coding work.
