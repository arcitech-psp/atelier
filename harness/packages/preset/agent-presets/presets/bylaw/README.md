# Bylaw Advisor

## Purpose

Explains land-use rules and permitting steps for a named jurisdiction.

## Tools

dsh-tool-web, dsh-tool-fs, dsh-tool-fs-search

## Services

Select a model in Settings and configure a web provider. The user supplies the jurisdiction and any property or project documents.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds a jurisdiction-neutral bylaw research profile; no local bylaw library is bundled.
