# Marco Polo

## Purpose

Finds, checks and summarizes public web sources with citations.

## Tools

dsh-tool-web, dsh-tool-fs, dsh-tool-fs-search

## Services

Select a model in Settings and configure a web provider. A workspace is optional for user-supplied research files.

Private app connectors are omitted; no unavailable connector names are shipped.

Adds Marco Polo for citation-first web research through the user's configured provider.
